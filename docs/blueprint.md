# **App Name**: Testlab

## Core Features:

- AI Insight Analyst: An AI-powered tool that interprets mock test data to identify learning gaps and recommends specific practice modules to improve rankings.
- Dynamic Mock Test Engine: A responsive testing interface simulating actual competitive exam environments with real-time timers and status tracking.
- Intelligent Exam Search: A high-performance search system with trending topic tags and categorized results for thousands of exam variants.
- Geographical Exam Hub: Dedicated state-level sections featuring localized competitive tests with unique region-specific card designs and data points.
- Live Performance Dashboard: A futuristic mockup interface visualizing user progress through interactive charts, percentile rankings, and difficulty badges.
- Interactive Exam Library: Categorized navigation allowing users to filter between SSC, Railway, Banking, and specialized teaching or medical exams.
- Leaderboard & Peer Analytics: A smart ranking system that benchmarks student performance against millions of other learners across the platform.

## Style Guidelines:

- The primary theme is 'Cyber Deep Navy'. Background: #0F172A (heavily desaturated deep blue for the default dark scheme).
- Primary Color: #6366F1 (Indigo), selected to evoke modern software trust. Accent: #06B6D4 (Cyan) to provide high contrast for interactive elements.
- Font pairing: 'Space Grotesk' for bold headlines to maintain a scientific/tech vibe; 'Inter' for body text for high readability and professional neutrality.
- A modern glassmorphic layout featuring large rounded cards, translucent blur effects on navbars, and bento-box style dashboard grids.
- Utilizes Lucide React for consistent, lightweight, and modern stroke-based icons across all categories and CTA buttons.
- Framers-motion based entrance animations, floating particle backgrounds, and glowing blur effects for an immersive futuristic atmosphere.
